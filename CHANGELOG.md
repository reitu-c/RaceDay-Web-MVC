# Changelog

All notable changes to the RaceDay MVC application are documented here.

## Version 1.0.0

### Added
- ASP.NET Core MVC frontend.
- Organiser and Participant interfaces.
- Session-based authentication.
- Role-specific navigation and protected routes.
- Event browsing and event management.
- Category management.
- Participant event enrolments.
- Results management and viewing.
- Participant profile editing.
- Profile picture uploads through the REST API.
- Azure Blob Storage integration.
- Docker container support.
- GitHub Actions build workflow.
- Project documentation and security guidelines.

### Improved
- Form validation and error handling.
- Responsive Bootstrap user interface.
- API communication through RaceDayApiService.
