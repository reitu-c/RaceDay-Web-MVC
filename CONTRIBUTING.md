# Contributing to RaceDay

Thank you for your interest in improving the RaceDay application.

## Development Guidelines

- Use C# and ASP.NET Core MVC for frontend development.
- Follow the existing project structure.
- Use meaningful names for classes, methods and variables.
- Keep API communication within the service layer.
- Do not allow the MVC application to access the database directly.
- Validate user input before submitting API requests.
- Follow the existing authentication and authorisation rules.

## Testing

- Build the application before submitting changes.
- Run relevant unit tests.
- Test affected features to avoid breaking existing functionality.

## Security

- Never commit passwords, API keys or connection-string secrets.
- Keep sensitive configuration in secure local settings.
- Protect role-specific functionality.

## Documentation

Update the README whenever significant application functionality or setup instructions change.
