# Security Policy

## Supported Versions

The current RaceDay MVC version is the supported version for security updates.

## Reporting a Vulnerability

If you discover a security vulnerability:

1. Do not publish sensitive details publicly.
2. Report the issue privately to the project maintainer.
3. Include steps to reproduce the issue.
4. Provide screenshots or error messages where appropriate.

## Security Measures

RaceDay uses:
- Session-based authentication.
- Role-based authorisation.
- Server-side input validation.
- HTTP-only session cookies.
- Secure handling of uploaded profile pictures.
- Azure Blob Storage for profile picture storage.

Never include passwords, API keys or other confidential information in issue reports.
